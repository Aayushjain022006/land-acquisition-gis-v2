# LandGuard AI

## Predictive Land Acquisition Monitoring & GIS Analytics

LandGuard AI is a prototype system for monitoring land acquisition projects using GIS, analytics and machine learning.

## Features

- Interactive GIS project map
- Land parcel visualization
- Plot ID and Parcel ID tracking
- Land possession status
- Risk heatmap
- Risk analytics
- Delay analytics
- Compensation analytics
- Machine learning based delay prediction
- Recommended actions for high-risk projects

## Technology Stack

- Python
- Pandas
- Scikit-learn
- Random Forest
- Folium
- Plotly
- Streamlit

## Run Locally

```bash
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
